One quiet, earned moment of pride — a boy who stammered through every school assembly finally reads the last line clear — an entry for make.fun's "One Line of Earned Pride" bounty ($5 in USDC).

## The line

> He'd stammered through every school assembly since he was seven; today he read the last line clear, and his little brother in the front row stood up first.

155 characters, one line. The full line also lives in `pride.txt`.

## Run it

```sh
python3 main.py
```

`main.py` writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt`), which is what the bounty judge reads. No network, no dependencies, deterministic.
